# control_system
A Python console application that simulates the control
of a tank and its main systems.

## Technologies

- Python
- Object-Oriented Programming (OOP)

## Features

- Crew assignment
- Engine control
- Fuel management
- Movement and speed control
- Direction selection
- Weapon selection
- Optical-electronic systems
- Night vision
- System diagnostics
- Technical specifications
- Distance and fuel calculations

## OOP Concepts

The project demonstrates:

- Classes and objects
- Inheritance
- Encapsulation
- Composition
- Interaction between objects
- Exception handling

## How to run

```bash
python main.py
